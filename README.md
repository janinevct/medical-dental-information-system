# Patient Management Module

 Module Scope

  The Patient Management Module is a core component of the Medical and Dental Information System that is responsible for organizing and maintaining patient information in a digital and systematic manner. This module allows clinic staff or administrators to efficiently manage patient records through CRUD (Create, Read, Update, Delete) operations.

  The module enables users to create new patient records by entering important patient details such as patient ID, full name, age, gender, address, contact number, and other necessary information. Once stored in the database, the records can be viewed in a table or list format for easier monitoring and management. In addition, the module allows authorized users to update or edit existing patient records whenever there are changes in patient information. Users can also delete records when necessary, with confirmation dialogs added as a safety measure to prevent accidental deletion of important data.
  
  Overall, the Patient Management Module helps simplify patient record handling, improves accessibility of information, reduces paperwork, and supports more organized clinic operations.


---

# Rationale

We chose the Patient Management Module because it is one of the core functions of a Medical and Dental Information System. This module helps organize and manage patient information efficiently, reducing manual record keeping and improving accessibility of data.

The module solves the technical challenge of handling patient data accurately and systematically through CRUD operations with validation and search functionality.

Features

- Create patient records
- View patient information
- Update patient details
- Delete patient records
- Search and filter patient data
